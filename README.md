# Web Page — HTML, CSS & JavaScript

This project is a web page developed using **HTML, CSS, and JavaScript**.

It was created as a front-end practice project to strengthen my understanding of the fundamental technologies used in web development, including page structure, styling, and JavaScript functionality.

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

---

## 📋 Project Overview

The project focuses on implementing a web interface using vanilla web technologies, without the use of frameworks or libraries.

Through this project, I practiced:

- Semantic HTML structure
- CSS styling and layouts
- JavaScript functionality
- DOM manipulation
- Event handling
- Organizing front-end files and code

---

## 🎨 Design

This project was inspired by a YouTube tutorial demonstrating how to build a fitness website using HTML, CSS, and vanilla JavaScript.

The purpose of this project was not to create an original design, but to practice translating an existing interface into functional HTML, CSS, and JavaScript.

---

## 📱 Project Limitations

This version was created before applying responsive design techniques, so the layout is primarily intended for desktop screens.

As part of my continued learning, I decided to rebuild and improve this project using **React**, focusing on:

- Responsive design
- Reusable components
- Improved architecture
- Better code organization
- User experience

---

## ⚛️ React Version

The new implementation will improve the original project by introducing a component-based architecture and a responsive design.
